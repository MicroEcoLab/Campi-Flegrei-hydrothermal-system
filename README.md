# Campi Flegrei hydrothermal system – 16S rRNA amplicon analysis

Scripts and data for the 16S rRNA gene amplicon analyses of the manuscript:

> Amico F., Amalfitano S., Corso D., Venturi S., Piacentini A., Biagi R., Fazi S., Tassi F.
> *From meteoric recharge to deep saline groundwater: coupling hydrogeochemistry and microbial community profiles in the Campi Flegrei hydrothermal system.* (submitted)

Raw reads: ENA, study accession **PRJEB127795**.

## Content

| File | Description |
|---|---|
| `dada2.Rmd` | Sequence processing (DADA2) |
| `phyloseq.Rmd` | Downstream analyses |
| `phyloseq_obj.rds` | phyloseq object produced by `dada2.Rmd` |
| `ENV_geochemical_dataset.tsv` | Environmental and geochemical data |
